# 環境設計書_可変要素一覧４（環境設計書生成用）

本書は環境設計書における可変要素の一覧表です。dip設計書の値を規定値として、変更後の値を入力できるよう項目を追加しています。

## 環境設計書生成ルール

### 記載ルール
1. **「変更後」が「-」の場合**: 該当リソースは使用しない（環境設計書に記載しない）
2. **「変更後」に具体的な値が記載されている場合**: その内容を環境設計書に反映する
3. **「変更後」が空欄の場合**: 規定値（dip設計書）の内容をそのまま環境設計書に反映する
4. **「変更後」に「[項目名]」形式の記載がある場合**: プロジェクト固有の値に置き換える必要があることを示す

### 生成時の処理フロー
1. 各セクションの項目を順次確認
2. 「変更後」の値に基づいて環境設計書への記載可否を判定
3. 記載対象の項目### 6.4 通知設定

## 使用方法

### 環境設計書生成時の手順

1. **プロジェクト要件の確認**: 各項目の「変更後」列に必要な値を入力
2. **リソース使用可否の判定**: 不要なリソースは「変更後」に「-」を記載
3. **環境設計書の生成**: 生成ルールに従って環境設計書を作成
4. **検証とレビュー**: 生成された環境設計書の内容を確認

### 各列の説明

1. **規定値（dip設計書）**: dip設計書で定義されている現在の設定値
2. **変更後**: 環境に応じて変更する場合の入力欄
   - 空欄：規定値をそのまま使用
   - 具体的な値：その値を使用
   - 「-」：該当リソースは使用しない
   - 「[項目名]」：プロジェクト固有の値に要置換
3. **AWS参考ドキュメント**: 該当設定のAWS公式ドキュメントへのリンク
4. **備考**: 設定項目の説明や注意事項

変更を行う際は、AWS参考ドキュメントを確認し、システム要件と照らし合わせて適切な値を設定してください。
