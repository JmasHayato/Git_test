## 主要な技術スタック

### コンピューティング
- **APIサーバー**: AWS Fargate (ECS)
- **Batchサーバー**: AWS Lambda
- **Bastion**: AWS Fargate (ECS)

### データベース・キャッシュ
- **データベース**: Amazon Aurora MySQL 3.04.3 (MySQL 8.0.28互換)
- **キャッシュ**: Amazon ElastiCache for Redis 7.1

### ネットワーク・CDN
- **VPC CIDR**: 172.30.80.0/22 (本番環境)
- **ロードバランサー**: Application Load Balancer (ALB)
- **CDN**: Amazon CloudFront
- **ドメイン**: dip-new-gate.com

### ストレージ・バックアップ
- **オブジェクトストレージ**: Amazon S3
- **コンテナレジストリ**: Amazon ECR
- **バックアップ**: AWS Backup

### セキュリティ
- **認証**: Amazon Cognito
- **WAF**: AWS WAF (マネージドルール適用)
- **暗号化キー管理**: AWS KMS
- **シークレット管理**: AWS Secrets Manager
- **脆弱性スキャン**: Amazon Inspector v2

### 監視・ログ
- **監視**: Amazon CloudWatch
- **操作履歴**: AWS CloudTrail
- **設定変更履歴**: AWS Config
- **通知**: Amazon SNS, AWS Chatbot

## リージョン構成

- **プライマリリージョン**: 東京リージョン (ap-northeast-1)
- **DRリージョン**: 大阪リージョン (ap-northeast-3)
- **使用AZ（東京）**: AZ-A, AZ-C, AZ-D
- **使用AZ（大阪）**: AZ-A, AZ-B, AZ-C

## 可用性・DR

- **目標稼働率**: 99.9%以上
- **RTO (目標復旧時間)**: 0.5営業日以内
- **RPO (目標復旧時点)**: 1営業日前（日次バックアップ）
- **DR戦略**: Cross-Region Backup + 手動構築
