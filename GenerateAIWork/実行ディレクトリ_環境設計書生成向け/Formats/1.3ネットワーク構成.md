# 1.3　ネットワーク構成

## 1.3.1 IPアドレスレンジ

今後VPN接続することを考慮しXXXX様環境にて使用していないIPアドレスレンジを使用する。

上記の要件により、[[別紙]システム構成図](./[別紙]システム構成図.md)に記載のIPアドレス体系とする。

## 1.3.2 サブネット

・明確なPublic/Privateサブネットに分ける明確な要件はない。\
しかし、システムの拡張性やAWSの一般的な構成を考慮し、Multi-AZのPublic/Privateの領域を定義し作成しておく。

上記の要件により、[[別紙]システム構成図](./[別紙]システム構成図.md)に記載のサブネット区分とする。

## 1.3.3 ルーティング

・PublicサブネットはInternet Gatewayを利用し、Internetへのデフォルトゲートウエイの経路を設定する。\
またS3へインターネットを経由しない経路としてエンドポイントを設定する。\
・PrivateサブネットはVPC内以外の経路を設定しない。\

上記の要件により、以下の様なルートテーブル構成とする。

### (1)ルートテーブル区分

|No.|環境|種別|Availability-Zone|名前|所属するサブネット|
|:-:|---|---|---|---|---|
|1|本番環境|DMZ|AZ-A<br>AZ-C<br>AZ-D|Production DMZ RouteTable|Production Public Subnet (AZ-A)<br>Production Public Subnet (AZ-C)<br>Production Public Subnet (AZ-D)|
|2|本番環境|Wab/AP|AZ-A<br>AZ-C<br>AZ-D|Production Web/AP RouteTable|Production Private Subnet (AZ-A)<br>Production Private Subnet (AZ-C)<br>Production Private Subnet (AZ-D)|
|3|本番環境|DB|AZ-A<br>AZ-C<br>AZ-D|Production DB RouteTable|Production Private Subnet (AZ-A)<br>Production Private Subnet (AZ-C)<br>Production Private Subnet (AZ-D)|

### (2)ルーティング設定

|No.|名前|ルーティング<br>宛先IP| <br>ターゲット|

|1|Production Publicルートテーブル|VPCのIPアドレスレンジ|VPC内|
| ||0.0.0.0/0|Internet Gateway|
| ||S3|S3エンドポイント|

## 1.3.4 Elastic IP

- NatGatewayおよびBastionサーバについては、IPアドレス固定化の為、Elastic IPを付与する。

## 1.3.5 カスタマーゲートウェイ

VPNでオンプレミスと接続する要件はないため、カスタマーゲートウェイは設定しない。

## 1.3.6 仮想プライベートゲートウェイ

VPN/Direct Connectでオンプレミスと接続する要件はないため、仮想プライベートゲートウェイは設定しない。

## 1.3.7 VPN接続

VPNでオンプレミスと接続する要件はないため、VPN接続は設定しない。

## 1.3.8 DirectConnect

VPN/Direct Connect等でオンプレミスと接続する要件はないため、VPN接続は設定しない。

## 1.3.9 Endpoint
