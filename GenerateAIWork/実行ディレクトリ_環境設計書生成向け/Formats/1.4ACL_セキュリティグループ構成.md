# 1.4 ACL/セキュリティグループ構成

## 1.4.1ネットワークACL

Subnet間の通信について、制御は行わない。  
上記の要件により、以下の様なネットワークACL構成とする。

### (1)ネットワークACL区分

|No.|環境|種別|Availability-Zone|名前|所属するサブネット|
|:-:|---|---|--|---|---|
|1|本番環境|DMZ|AZ-A<br>AZ-C<br>AZ-D|Prduction DMZ NetWork ACL|Prduction Public Subnet (AZ-A)<br>Prduction Public Subnet (AZ-C)<br>Prduction Public Subnet (AZ-D)|
|2|本番環境|Web/AP|AZ-A<br>AZ-C<br>AZ-D|Prduction Web/AP NetWork ACL|Prduction Private Subnet (AZ-A)<br>Prduction Private Subnet (AZ-C)<br>Prduction Private Subnet (AZ-D)|
|3|本番環境|DB|AZ-A<br>AZ-C<br>AZ-D|Prduction DB NetWork ACL|Prduction Private Subnet (AZ-A)<br>Prduction Private Subnet (AZ-C)<br>Prduction Private Subnet (AZ-D)|

### （２）ネットワークACL設定

## 1.4.2 セキュリティグループ

- 各ノードにそれぞれセキュリティグループを設定し、詳細な通信制限を行う。
- インバウンド通信に関しては、必要最小限の通信のみ開放する。
- アウトバウンド通信に関しては制限を実施しない。

上記の要件により、以下の様なセキュリティグループ構成とする。

### (1)セキュリティグループ区分

|No.|環境|適用ノード|名前|
|:-:|---|---|---|
|1|本番環境|Web/AP Server|Prduction web/AP Server SecurityGroup|
|2|本番環境|DB|Prduction DB SecurityGroup|
|3|本番環境|ELB|Prduction ELB SecurityGroup|
|4|本番環境|Bastion Server|Prduction Bastion Server SecurityGroup|

### (2)セキュリティグループ設定

|No.|名前|方向|タイプ|プロトコル|ポート範囲|送信元/送信先|
|:-:|---|---|---|---|---|---|
|1|Prduction ELB SecurityGroup|インバウンド  |HTTP|TCP|80|0.0.0.0/0|
| |                           |             |HTTPS|TCP|443|0.0.0.0/0|
| ||アウトバウンド|すべてのトラフィック|すべて|すべて|0.0.0.0/0|
|2|Prduction Web/AP SecurityGroup|インバウンド|HTTP|TCP|80|Prduction ELB SecurityGroup|
| |                           |             |SSH|TCP|22|Prduction Bastion SecurityGroup|
| ||アウトバウンド|すべてのトラフィック|すべて|すべて|0.0.0.0/0|
|3|Prduction DB SecurityGroup|インバウンド|MYSQL|TCP|3306|Prduction Web/AP SecurityGroup|
|||アウトバウンド|すべてのトラフィック|すべて|すべて|0.0.0.0/0|

※セキュリティグループは許可設定のみが設定可能。ルール当てはまらない通信はすべて拒否される。
