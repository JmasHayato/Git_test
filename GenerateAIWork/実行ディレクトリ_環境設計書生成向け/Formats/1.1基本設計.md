# 1.1　基本設計

## 1.1.1 利用サービス(AWS、その他)

本システムは、Amazon Web Services （以下AWS）上に構築するものとする。 \
本システムのインフラ環境は、AWSの以下のメニュー及びその他サービスを利用する。

|サービス|メニュー項目|サービス|詳細|説明|
|--|---|---|---|---|
|AWS|サーバ|EC2|Instance|Centerサーバ/StudioPCで利用する。|
||ストレージ|EBS|Volume|EC2 Instanceの仮想ディスクとして利用する。
|||S3|EBSスナップショット|日次のスナップショットにより、EBS Snapshotを保存する。|
||||DBダンプ|各状態に応じたDBダンプファイルを保存する。|
||ネットワーク|FW|Security Group/ACL|IP/Portによる通信制限のため利用する。|
|||VPC||IaaSサービスの利用によるPrivateNW空間作成のためVPCを利用する。|
|||Shield|Standard|ネットワークおよびトランスポートレイヤーの DDoS 攻撃を防御する。|
||ツール|CloudFormation|リソースデプロイメント|環境構築の自動化に利用する。|
|||Service Catalog|サービスの一元的管理|CloudFormationで自動作成する各サーバのバージョン管理に利用する。|
|||SSM|Session Manager|EC2 InstanceのOS上の操作のために利用する。(ポートフォアード機能)|
||ユーザ管理|IAM||AWSのサービス・リソース利用にあたってのユーザ/サーバ権限を制御する。|
