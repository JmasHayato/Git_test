### (3)ロードバランサ

本システムではApplication Load Balancerを採用し、以下の実装を行う。

- ロードバランシングの対象インスタンスとして、それぞれ異なるアベイラビリティ―ゾーン(AZ)上のWeb/APサーバ1系・2系を配置する。(ターゲットグループ)
- 各サイトへの振り分けは同じWeb/APサーバ内となる為、ターゲットグループは共通の構成とする。
- クロスゾーン負荷分散(Cross-Zone Load Balancing)を有効化し、アベイラビリティーゾーンに関わらず全ての対象インスタンスに対し均等にロードバランシングを行う。

- ロードバランサにSSL証明書を設定し、アクセラレートを行う。
- Connection Drainingを有効にする事により、メンテナンス等でインスタンスを切り離す場合において、設定時間の間は、リクエスト中の通信を切断しないように設定する。
- ELBのヘルスチェック機能により、バランシング対象インスタンスの死活監視を行い、指定された閾値によりバランシング対象からの除外と復旧を行う。
- 専用のセキュリティグループを作成し、アクセス制御を行う。
- ALBの機能により、URLリダイレクトを行う。ルールは以下の通り。

|No.|環境|種別|受信ポート|判定順|判定内容|アクション種別|アクション|表示イメージ|
|:-:|---|---|---|---|---|---|---|---|
|1|本番|ELB|80|1|-|リダイレクト|httpsにリダイレクトする|http://xxxxx → https://xxxx |
|2|本番|ELB|443|1|ホスト名がwww.jmas.co.jpか|転送|Webサーバ用ターゲットグループに転送する|正常表示|
|3|本番|ELB|443|2|それ以外|固定レスポンス|エラー応答を返却する|エラー応答画面表示|

### (4)Web/APサーバ構成

Web/APサーバは、本システムのWebインターフェース及びアプリケーションサーバ機能を提供する。
2台以上による冗長構成(Active/Active)とし、インターネットからの接続に対してロードバランサー(ALB)からの振り分けにより、負荷分散を行う構成とする。
ステージングWeb/APサーバは本番と同様に2台以上の冗長構成、開発Web/APサーバはシングル構成とする。

- HTTPサーバ機能は、Apache Web Server を採用する。
- ALBからの HTTPリクエスト に対して、静的コンテンツ及びPHPにより生成した動的コンテンツを応答として返す。
- APサーバ機能は、PHP を採用する。
- PHPによる動的コンテンツの生成、DBへのSQLクエリを行う。
- 利用者向けWebサイト、管理者向けWebへのアクセスはPATH(/)でサイトを分ける構成とする。
- 管理者向けWebへのアクセス制御はアプリケーションで実装する。

AutoScaling構成

- 本番/ステージングWeb/APサーバはAutoScaling構成とし、必要に応じてスケールアウト可能な構成とする。
- 初期構成は起動台数を２台とし、自動で２台以上スケールアウトしない設定とする。
- ALBのヘルスチェックによって接続不可となったインスタンスについては削除し、登録済みのAMIから新しいインスタンスを起動する。
  １つのAZが異常または使用不可になったときは影響を受けていないAZに起動し、正常な状態に戻ると自動的にすべてのAZにわたって均等にインスタンスを再分散する。
- スケールイン時、削除されるインスタンスは終了ポリシーによりもっとも古いインスタンスから削除する。
- スケールアウト時、ユーザデータを使用しミドルウェアの導入及びアプリケーションのデプロイを実行する。
  - CodeDeployエージェント
  - DeepSecurityエージェント
  - アプリケーションのデプロイ(CodeDeploy)

### (5)DBサーバ構成

DBサーバは、本システムのRDBMS機能を提供する。
本番/ステージングDBサーバはAmazon RDS上でのMulti-AZ 配置による冗長構成(Writer/Reader)とする。開発DBサーバはシングル構成とする。

- Amazon RDSではMasterとReplica間との同期によるタイムラグ(レプリケーションラグ)は発生しない。
- RDBMSサーバ機能は、 Amazon Aurora MySQLを採用する。
- Web/APサーバからのSQLクエリに対し、RDBMSとしての処理結果を返す。

### (6)メールサーバ構成 (SNS)

本システムでは、AWSからの監視発報メール送信としてAWS の SNSを利用する。
