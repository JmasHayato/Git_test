# インフラアーキテクチャ方針書

## セキュリティ対策

### 想定される攻撃とセキュリティ対策

| 攻撃の概要                                                                                          | 採用するアーキテクチャ                            | セキュリティ対策概要                                                                                               |
| --------------------------------------------------------------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| 不正アクセス                                                                                        | CloudTrail `<br>` CloudTrail `<br>` GuardDuty | AWSリソースの変更を検知する `<br>` AWS API履歴を保管する `<br>` 悪意のあるアクティビティや不正な動作を監視する |
| ポートスキャン                                                                                      | SecurityGroup                                     | アクセス元、ポートの制限を行う                                                                                     |
| DDoS攻撃                                                                                            | AWS Shield                                        | ネットワークレイヤー、トランスポートレイヤーへのDDoS攻撃を自動で検知し防御する                                     |
| アプリケーションの脆弱性を狙った攻撃 `<br>` ※SQLインジェクション、クロスサイトスクリプティング等 | AWS WAF                                           | SQLインジェクション、クロスサイトスクリプティング、Botをフィルタするルールを設定する                               |
| OS、パッケージの脆弱性を狙った攻撃                                                                  | Inspector v2                                      | ECRイメージの脆弱性スキャンを行う                                                                                  |
| その他                                                                                              | Fargate                                           | コンテナユーザは書き込み不可の権限を設定する                                                                       |

### その他の対策（手動更新）

例：セキュリティ対策状況の可視化のためSecurityHub を使用する。
