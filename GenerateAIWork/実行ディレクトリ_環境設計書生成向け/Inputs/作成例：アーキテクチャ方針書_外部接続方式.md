# アーキテクチャ方針書_外部接続方式（結果２）

## 外部接続方式

### 処理方式概要
外部システムとは原則閉塞網で接続する。ただし、SaaS製品への接続はインターネット経由で行うものとする。

| パターン | 採用するアーキテクチャ | 考慮事項 |
| -------- | ---------------------- | -------- |
| 閉塞網接続 | VPC Peering, Direct Connect, Transit Gateway, Lambda, Aurora | セキュリティグループ・ルート設定、帯域・冗長性、コスト管理 |
| インターネット接続 | API Gateway, WAF, ALB, Lambda | 認証・認可、DDoS対策、通信暗号化、WAFルール設計 |
| SaaS接続 | PrivateLink, VPN, NAT Gateway, Lambda | SaaS側仕様確認、通信経路の暗号化、可用性・障害時対応 |

### 実現イメージ

#### 閉塞網接続（VPC Peering）

```mermaid
sequenceDiagram
    participant User as 内部システム
    participant SG1 as セキュリティグループA
    participant VPC_A as VPC-A
    participant Peering as VPC Peering
    participant VPC_B as VPC-B
    participant SG2 as セキュリティグループB
    participant External as 外部システム
    
    User->>SG1: リクエスト送信
    SG1->>VPC_A: 通信許可
    VPC_A->>Peering: ルート設定に基づく転送
    Peering->>VPC_B: ピアリング接続経由
    VPC_B->>SG2: 宛先確認
    SG2->>External: 外部システムへ転送
    External-->>SG2: レスポンス
    SG2-->>VPC_B: 応答転送
    VPC_B-->>Peering: ピアリング経由で返却
    Peering-->>VPC_A: 応答転送
    VPC_A-->>SG1: 応答転送
    SG1-->>User: 応答受信
```

#### 閉塞網接続（外部アプリ ⇔ Aurora）

```mermaid
sequenceDiagram
    participant ExtApp as 外部アプリケーション
    participant VPC_Ext as 外部VPC
    participant Peering as VPC Peering/Transit Gateway
    participant VPC_DB as データベースVPC
    participant SG as セキュリティグループ
    participant Subnet as プライベートサブネット
    participant Aurora as Aurora DB
    
    ExtApp->>VPC_Ext: データベース接続要求
    VPC_Ext->>Peering: 閉塞網経由で接続
    Peering->>VPC_DB: データベースVPCへ転送
    VPC_DB->>SG: セキュリティグループ確認
    SG->>SG: DB接続許可ポート確認
    SG->>Subnet: プライベートサブネット経由
    Subnet->>Aurora: データベース接続
    Aurora->>Aurora: SQL実行・データ処理
    Aurora-->>Subnet: クエリ結果
    Subnet-->>SG: 応答転送
    SG-->>VPC_DB: 応答転送
    VPC_DB-->>Peering: 閉塞網経由で返却
    Peering-->>VPC_Ext: 外部VPCへ返却
    VPC_Ext-->>ExtApp: 処理結果受信
```

#### SaaS接続（NAT Gateway + Lambda）

```mermaid
sequenceDiagram
    participant User as 内部アプリケーション
    participant VPC as VPC
    participant Lambda as Lambda関数
    participant NAT as NAT Gateway
    participant Internet as インターネット
    participant SaaS as SaaSサービス
    
    User->>VPC: SaaS連携要求
    VPC->>Lambda: Lambda関数呼び出し
    Lambda->>Lambda: 認証情報・パラメータ準備
    Lambda->>NAT: NAT Gateway経由でアウトバウンド通信
    NAT->>Internet: パブリックIP変換後インターネット経由
    Internet->>SaaS: API呼び出し（HTTPS）
    SaaS-->>Internet: SaaSレスポンス
    Internet-->>NAT: 応答転送
    NAT-->>Lambda: 応答受信
    Lambda->>Lambda: レスポンス加工・エラーハンドリング
    Lambda-->>VPC: 処理結果
    VPC-->>User: 最終レスポンス
```
