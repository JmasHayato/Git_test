# インフラアーキテクチャ方針書

## ログ連携方式

### 処理方式概要

障害対応、不正アクセス調査等を行うためにログを取得し参照できる状態にする。

ログはAWSの機能によりCloudWatchLogs、S3に出力される。

#### ログ出力先

| サービス                    | 出力先         |
| --------------------------- | -------------- |
| Fargate                     | CloudWatchLogs |
| Lambda                      | CloudWatchLogs |
| StepFunctions               | CloudWatchLogs |
| Aurora                      | CloudWatchLogs |
| Elasticache                 | CloudWatchLogs |
| Kinesis Firehose            | CloudWatchLogs |
| Chatbot                     | CloudWatchLogs |
| CloudFront                  | S3             |
| ALB                         | S3             |
| WAF                         | S3             |
| VPCフローログ               | S3             |
| SES                         | S3             |
| SSM（セッションマネージャ） | S3             |
