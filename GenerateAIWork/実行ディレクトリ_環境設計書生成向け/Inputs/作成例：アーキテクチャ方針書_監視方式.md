# インフラアーキテクチャ方針書

## 監視方式

### 処理方式概要

| パターン       | 採用するアーキテクチャ                | 考慮事項     |
| -------------- | ------------------------------------- | ------------ |
| メトリクス監視 | CloudWatch、EventBridge、SNS、Chatbot | （手動更新） |
| ログ監視       | CloudWatch、EventBridge、SNS、Chatbot | （手動更新） |
| イベント監視   | EventBridge、SNS、Chatbot             | （手動更新） |

### 実現イメージ

#### メトリクス監視パターンのシーケンス図

```mermaid
sequenceDiagram
    participant Apps as アプリケーション
    participant CW as CloudWatch
    participant EB as EventBridge
    participant SNS as SNS
    participant CB as Chatbot
    participant Teams as Microsoft Teams

    Apps->>CW: メトリクス送信
    CW->>CW: メトリクス蓄積・監視
    Note over CW: しきい値チェック
    CW->>EB: アラーム発生時イベント送信
    EB->>SNS: イベント転送
    SNS->>CB: 通知メッセージ送信
    CB->>Teams: アラート通知
```

#### ログ監視パターンのシーケンス図

```mermaid
sequenceDiagram
    participant Apps as アプリケーション
    participant CWL as CloudWatch Logs
    participant CW as CloudWatch
    participant EB as EventBridge
    participant SNS as SNS
    participant CB as Chatbot
    participant Teams as Microsoft Teams

    Apps->>CWL: ログ出力
    CWL->>CWL: ログ蓄積
    CWL->>CW: メトリクスフィルタ適用
    Note over CW: エラーログ検知等
    CW->>EB: アラーム発生時イベント送信
    EB->>SNS: イベント転送
    SNS->>CB: 通知メッセージ送信
    CB->>Teams: アラート通知
```

#### イベント監視パターンのシーケンス図

```mermaid
sequenceDiagram
    participant AWS as AWSサービス
    participant EB as EventBridge
    participant SNS as SNS
    participant CB as Chatbot
    participant Teams as Microsoft Teams

    AWS->>EB: システムイベント発生
    Note over EB: EC2状態変化、<br/>セキュリティイベント等
    EB->>EB: ルールに基づくイベント処理
    EB->>SNS: 対象イベント転送
    SNS->>CB: 通知メッセージ送信
    CB->>Teams: イベント通知
```
