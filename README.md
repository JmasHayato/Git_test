## Amazon Q と GitHub 連携調査

このリポジトリでは、Amazon Q Developer と GitHub の連携について包括的な調査を実施しました。

### 調査文書

- **[Amazon Q と GitHub 連携調査報告書](docs/amazon-q-github-integration-investigation.md)** - 連携の概要、メリット、課題、改善提案
- **[実装例とサンプルコード](docs/amazon-q-github-integration-examples.md)** - GitHub Actions、VSCode設定、実装パターン

### 主な発見事項

1. **既存統合**: プロジェクトは既にAmazon Q DeveloperとGitHub Copilotを効果的に活用
2. **効率向上**: AI支援による文書作成とコード生成の自動化を実現
3. **品質保証**: AWS Well-Architected Frameworkに準拠した一貫性のある設計書生成
4. **改善余地**: セキュリティ強化、自動化レベル向上、チーム展開の可能性

### 対象プロジェクト
JMA Systems AWS インフラ環境設計書プロジェクト - 生成AIを活用したテンプレートベースの自動化による包括的なAWS環境設計書の生成
